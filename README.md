# Program Security (français)

Traduction française, à usage privé, du dojo **Program Security** de [pwn.college](https://pwn.college).

Ce dépôt ne contient ni le code des défis, ni leurs vérifications : les défis sont importés du dojo officiel `program-security`, avec les mêmes environnements et les mêmes flags. Seuls les textes sont traduits : noms et descriptions des modules et des défis.

## Contenu

- `dojo.yml` : déclaration du dojo et de ses cinq modules, importés du dojo officiel.
- Un dossier par module avec `module.yml`, `DESCRIPTION.md` et un dossier par défi.
- Le défi `return-oriented-programming/demo-take-it-or-leave-it` n'a pas d'énoncé dans la source : il n'a pas de description.
- `GLOSSAIRE.md` : termes techniques retenus.

## Installation sur pwn.college

Même procédure que pour les autres dojos traduits : créer le dojo à partir de `cchopin/program-security-fr` sur pwn.college, ajouter la clé de déploiement affichée par le formulaire en lecture seule sur le dépôt, puis valider. Le dojo est déclaré `type: hidden`.

Les liens internes pointent vers `https://pwn.college/program-security-fr/…` ; ils ne fonctionnent qu'après l'installation.
