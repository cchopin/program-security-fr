*Introduction ajoutée pour cette traduction, hors traduction directe.*

La programmation orientée retour (ROP) consiste à enchaîner des fragments de code déjà présents dans le programme ou dans la bibliothèque libc, pour exécuter ce qu'on veut sans injecter de code. Ce module construit la technique pas à pas : écraser une adresse de retour, enchaîner plusieurs fonctions, s'appuyer sur une fuite de pile ou de libc, pivoter la pile, puis contourner un canari ou un serveur à fourche.

Les défis existent en deux versions, facile et difficile. Les énoncés ne donnent aucune solution.
