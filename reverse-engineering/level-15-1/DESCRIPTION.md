Plongeons dans la rétro-ingénierie de code obfusqué !
Ce défi utilise une obfuscation à base de machine virtuelle : il faut faire de la rétro-ingénierie sur l'émulateur et l'architecture personnalisés pour comprendre comment obtenir le flag !
Avec un peu de malice, on n'a pas besoin de rétro-ingénierie _trop_ poussée du code de la machine virtuelle.
